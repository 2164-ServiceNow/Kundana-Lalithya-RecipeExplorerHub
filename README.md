# Project Title: Recipe Explorer Hub
## Overview:
A Single Page Application (SPA) designed to help users discover, save, and explore recipes tailored to their preferences. The app allows users to search for recipes using ingredients, filter by cuisine type, and view detailed nutritional information. It also provides features to save favorite recipes, sort them by cooking time, and explore e-book versions for offline access.

## Technologies Used:
* HTML
* CSS
* JavaScript
* AngularJS
* TheMealDB API(https://www.themealdb.com/api.php)

## User Stories:

- As a USER, I want to search for recipes by entering ingredients so I can use available items.
- As a USER, I want to filter recipes by cuisine type (e.g., Italian, Indian) to explore new flavors.
- As a USER, I want to view detailed instructions and ingredients for a selected recipe.
- As a USER, I want to see the nutritional value of a recipe to make healthy choices.
- As a USER, I want to save recipes I like for future reference.
- As a USER, I want to sort recipes by cooking time to find quick meal options.
- As a USER, I want to find recipes that are available as e-books for offline access.
- As a USER, I want to search for recipes by name or keyword to find specific dishes.
